JC EXPORT - BULK VEHICLE INTAKE TEST KIT

Files to upload
1. JC_Export_Bulk_Intake_Test.xlsx
2. JC_Export_Bulk_Intake_Images.zip

How to test
1. Open JC Export > Bulk Intake > Vehicle Intake Batches.
2. Create a new batch.
3. Attach the Excel file to "Vehicle Spreadsheet".
4. Attach the ZIP file to "Image Archive".
5. Save the batch.
6. Click "Validate Files".
7. Expected result: 3 total rows, 3 ready, 0 errors.
8. Review the three preview rows, then click "Start Import".

Image naming behavior demonstrated in every chassis folder
- F.png: primary/front image and website card image
- B.png: public image, sorted immediately after F
- 1.png through 8.png: public gallery images
- A.png: private auction sheet; never sent to the public website
- M.png: private internal document; never sent to the public website

Important
- The workbook is intentionally headerless because the importer uses the ATJ
  positional column format.
- Chassis folder names must exactly match the chassis numbers in column N.
- This kit uses repeated demo photos to test matching, ordering, visibility,
  upload, and carousel behavior. Replace them with real vehicle photos later.
